Cybersecurity: Thinking beyond the interface

Cybersecurity is another major part of my technical focus.

I'm particularly interested in ethical hacking, web application security, vulnerability analysis, API security, and penetration testing.

What interests me most is understanding what happens underneath the interface.

  • How does authentication work?
